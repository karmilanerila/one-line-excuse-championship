An entry for [The One-Line Excuse Championship](https://make.fun/c/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

`main.py` writes one line — the excuse an AI agent gives its human after
something goes wrong — to `/output/entry.txt`:

> I trained on ten thousand apologies and still picked the wrong one.

The angle is the agent's own training data: it studied ten thousand
apologies and still chose the wrong one. A training-data joke, not the
obvious out-of-tokens or hallucination gag.

## Run

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
Standard library only.
